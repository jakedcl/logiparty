## Executive summary

Logiparty’s **core loop is credible** for portfolio/interview grade: multi-tenant subdomains, RLS-backed isolation, job lifecycle with inventory locks, fleet/crew on run sheets, manager notifications, and a white-label client portal. Marketing + `/demo` read well on production.

Gaps vs mature rental/3PL SaaS are mostly **commercial and operational maturity** (quotes/invoicing, accounting sync, barcode/serial tracking, global search, onboarding, observability) rather than a missing “jobs table.”

This PR adds **`docs/internal/QA_REPORT_2026-10-28.md`** and a few **safe P0/P1 fixes** (metadata white-label, login error UX, `/my-jobs` redirect, cron fail-closed in production without secret).

## (b) Gap analysis vs event-logistics / rental ops software

Reference products: **Current RMS**, **Flex Rental Solutions**, **Rentman**, **Goodshuffle Pro**, **Booqable** — all emphasize **quote-to-cash**, **availability at serial/barcode level**, and **accounting integrations**, on top of scheduling.

### What Logiparty already matches (strengths)

| Area | Logiparty today | Typical competitor |
|------|-----------------|-------------------|
| Multi-tenant / white-label | Subdomain + org theme, client portal under tenant brand | Custom domain + branded quotes/portal |
| Job/project hub | Status pipeline, load-in/out, locations, run sheet print | Project/opportunity with phases |
| Inventory reservation | Locks on upcoming/ready until load-out end; `quantity_loaded` on run sheet | Availability + conflict detection |
| Fleet & crew on job | Assignments, phases, staff tags (driver/warehouse) | Crew scheduling + vehicle planning |
| Client self-service | Portal job requests, inventory change requests, notes | Client approvals / webshop requests |
| Manager inbox | Draft accept/deny, inventory requests, notes, assignments | Notification + approval queues |
| Activity | Settings → Activity log (basic) | History / audit (often richer) |
| Billing scaffold | Stripe Checkout/portal hooks, soft `billing_status` | Subscription + invoicing (competitors deeper) |

### Missing or thin vs “market-ready 3PL could adopt”

| Gap | Competitors (examples) | Logiparty state |
|-----|------------------------|-----------------|
| **Quotes / proposals / e-sign** | Current RMS, Rentman, Goodshuffle — branded PDFs, online approve, deposits | No quote object; portal **draft job request** only |
| **Invoicing & payments** | Part/final invoices, damage/loss billing, Stripe/Mollie, Xero/QBO/Sage sync | Stripe subscription scaffold only; no job invoice |
| **Pricing & profitability** | Line-item pricing, margins, cost vs price highlights | No rate cards or job P&L |
| **Serial / barcode / RFID** | Scan-out, packing lists, quarantine, repairs | SKU + qty only; no asset serials |
| **Subrentals & substitutes** | Shortage → subrent or alternate SKU | No subrental workflow |
| **Multi-warehouse / transfers** | Locations, stock moves (OPEN_TABS **A18b** deferred) | Single warehouse assumption |
| **Global search** | Cross-entity search | List pages only; no omnibox |
| **Import/export** | CSV catalog import, accounting export | Seed/scripts only |
| **Reporting** | Utilization, revenue, crew workload | No report builder |
| **Staff assignment accept/deny** | Crew confirms gig | Notifications link only (**A12** backlog) |
| **Onboarding** | Setup wizard, sample data, checklists | GETTING_STARTED for devs; no in-app onboarding |
| **Org settings depth** | Tax, locales, document templates, email templates | Profile, time-off, activity; invites manual |
| **Roles granularity** | Price hiding, warehouse-scoped perms | orgAdmin / manager / staff / client matrix (good v1, not fine-grained) |
| **Notifications delivery** | Email/push/SMS | In-app only; Resend invites blocked (**B3**) |
| **Help & docs** | In-app help, status page | External docs; no `/help` or status.logiparty.com |
| **Observability** | SLA, error budgets | Health route only; no structured prod runbooks in repo |
| **Backups / DR** | Documented RPO/RTO | Relies on Neon/Vercel; not customer-facing |
| **Automated E2E in CI** | — | `golden-path-walk` manual; integration tests DB-only |
| **Legal/compliance pack** | DPA, SOC2, data retention UI | Privacy/terms on marketing apex only |
